# Plan: Fix Button Alignment & Mobile Sidebar

## Problem 1: Buttons not aligned on mobile
**File**: `lcyksp-front/src/views/VideoDownloadView.vue`

On mobile, the secondary buttons ("下载全部图片", "放大预览") don't stretch to full width. The `width: 100%` on `.primary-action`/`.secondary-action` is being overridden by Element Plus internal button styles.

**Fix**: Add `:deep(.el-button)` rule inside `.action-row` to force full width:
```css
.action-row :deep(.el-button) {
  flex: 1;
  min-width: 0;
  width: 100% !important;
}
```

## Problem 2: Sidebar open by default on mobile
**File**: `lcyksp-front/src/App.vue`

Line 40: `const sidebarCollapsed = ref(false)` — sidebar starts open. On mobile (below 768px), this means the sidebar overlay covers the page on first load.

**Fix**: Initialize `sidebarCollapsed` based on screen width:
```js
const sidebarCollapsed = ref(typeof window !== 'undefined' ? window.innerWidth < 768 : false)
```
